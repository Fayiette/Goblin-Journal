# Workspace Guidelines

## No Emojis Rule
- Under no circumstances should emojis be used anywhere:
  - Do not use emojis in assistant responses or explanations.
  - Do not use emojis in documentation, markdown files, READMEs, or changelogs.
  - Do not use emojis in UI mockups, HTML, CSS, or labels.
  - Do not use emojis in code, comments, strings, or commit messages.

## UI/UX Design-First Rule
- For any UI/UX changes, additions, or redesigns:
  1. A visual prototype/mockup must be created in the `mockup/` folder first (as `.html` or visually previewable file).
  2. The mockup must demonstrate layout, component styling, color schemes, and controls.
  3. Coding in Lua/XML is performed only based on the finalized mockup design.
